# PrintForge local release report · 2026-08-30

## Result

The multi-workspace release is deployed as a public GitHub Pages **preview** at
[jakubgal.github.io/printforge-medal-designer](https://jakubgal.github.io/printforge-medal-designer/).
It is not yet signed off as the commercial production deployment because the
custom domain and full Firefox, Safari/WebKit, mobile, and independent-file

## Defects found and repaired during the run

1. Mobile hid the project-name and explicit Save controls. Both now remain in
   the compact header down to 320 px.
2. The compact Quick Tour sat below transform handles, intercepting Layers.
   Its card now sits above model gizmos.
3. A calculated preview cell size could round downward, allocating 722,500
   cells against a 720,000 budget. Cell size now rounds upward by at most
   0.001 mm, retaining printer-irrelevant detail while honoring memory limits;
   a regression test covers it.
4. Geometry-preflight failures left PDF enabled even though PDF also needs the
   geometry. PDF now follows the same geometry blocker state as 3MF/STL/STEP.
5. QA fixtures still wrote a few local preferences. All project, inventory, AI,
   ribbon, and onboarding preference writes are now suppressed in QA mode.
6. The 404 page used CSP-blocked inline JavaScript. It now uses a packaged
   same-origin script and handles project-site roots without an inline policy
   exception.
